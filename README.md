# 游戏运营驾驶舱 · 游戏运营数据分析平台

面向游戏用户运营 / 运营分析的核心指标驾驶舱，覆盖**规模 → 收入 → 留存 → 付费 → 流失**五条主线，所有指标交叉自洽（流水 = DAU × 付费率 × ARPPU），规则引擎自动输出运营动作建议。

## 功能模块

### 一、核心指标（三组 KPI）
- **用户规模**：DAU（7日均，环比）、MAU（估算）、日均新增、人均时长
- **收入变现**：30日流水（环比）、ARPU、ARPPU、付费率
- **留存质量**：D1/D7 留存（vs 历史周对比）、新增 LTV（30日）、7日活跃率

### 二、营收与用户趋势
- 日流水柱状图 + 付费率折线图（双轴），运营活动节点自动标注（▲）
- DAU 面积图 + 日均新增柱状图

### 三、留存分析
- 新增用户留存矩阵（Cohort，按周 D1/D3/D7/D14/D30，热力色阶）
- 最近 4 个新增周的留存曲线对比（D1–D30 对数横轴）

### 四、付费分析
- 付费转化漏斗（下载 → 注册 → 创角 → 完成引导 → 首日付费），自动标注最大流失点
- 付费档位分布（648/328/128/68/≤30 元笔数占比）
- 新增用户 LTV 曲线（D1–D30）+ CAC 回本线标注
- 付费用户四层分层（鲸鱼 ≥2000 / 海豚 300-2000 / 小鱼 <300 / 非付费）

### 五、运营复盘与预警
- 运营活动 ROI 复盘表（增量营收口径，自动给「保持/缩量/停投」建议）
- RFM 高流失风险用户预警（鲸鱼/海豚 + 近7日未登录，含风险分与差异化召回动作）

### 六、运营动作中心
- 规则引擎自动生成 4–5 条优先级排序的动作卡片（红/黄/蓝/绿四级），每条含问题诊断、建议动作、预估 ROI

### 七、交互
- 时间范围切换：近 7 日 / 近 30 日 / 近 90 日，所有图表与 KPI 联动刷新

## 使用

双击 `index.html`，原生 HTML/CSS/JS + SVG，无第三方依赖、无需联网。

## 数据说明

当前为 90 天脱敏演示数据（确定性伪随机，指标交叉自洽：`revenue = round(round(dau × payRate) × arppu)`）。替换真实数据时按 `{date, dau, nu, payers, payRate, arppu, revenue, play_minutes, sess}` 结构接入即可，规则引擎与展示逻辑无需改动。指标口径可对齐 ThinkingData / 自建数仓导出。

## 面试可讲

- **看数先看结构**：三组 KPI（规模/收入/质量）对应运营三条生命线——没人（DAU）、没钱（流水）、留不住（留存）
- **留存衰减是健康度核心**：Cohort 矩阵看新手期（D7 < 20% 排查前 10 分钟卡点），曲线对比看版本优化是否有效（W-1 vs W-8 的 D1/D7 提升）
- **付费漏斗找最大流失点**：本例在「完成引导 → 首日付费」（38.2%），对应动作是引导结束节点投首充礼包
- **LTV + CAC 定买量**：D7 LTV 占 D30 的 28%，可用于快速估算买量回收周期；回本天数 = CAC 对应的 LTV 天数
- **鲸鱼是命脉**：0.8% 的鲸鱼贡献 42% 流水，流失预警的 ROI 远高于拉新；按 RFM 风险分排序召回，而不是群发
- **活动 ROI 必须用增量口径**：活动期流水 − 同期基线，否则每场大促"看起来都赚钱"
- **动作中心的价值**：看板不只是报数，而是给可执行的动作——亏损预警给改善窗口、标杆沉淀 SOP 复制、低 ROI 活动缩预算
