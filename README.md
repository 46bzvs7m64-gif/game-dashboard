# 游戏运营数据分析看板

面向游戏用户运营 / 运营分析的核心指标看板，覆盖获客、留存、付费、流失预警四条主线。

## 功能

- 核心指标：DAU、日均新增、付费率、ARPPU、30 天流水、新增 LTV
- DAU / 新增趋势、每日流水与付费率双图
- 新增用户留存矩阵（Cohort，按周 D1/D3/D7/D14/D30，热力色阶）
- 付费用户分层：鲸鱼 / 海豚 / 小鱼 / 非付费，各层人数占比与流水贡献
- 流失预警：自动圈选"鲸鱼海豚 + 近 7 日未登录"用户，给出差异化召回动作（648 礼包 / 回归券 / 电话回访）

## 使用

双击 `index.html`，原生 HTML/CSS/JS + SVG，无第三方依赖。

## 数据说明

当前为 90 天脱敏演示数据（确定性伪随机，口径可对齐 ThinkingData / 自建数仓导出）。替换真实数据时按 `{date,dau,nu,payers,payRate,revenue}` 结构接入即可。

## 面试可讲

- 留存矩阵看新手期健康度（D7 低于 25% 排查前 10 分钟卡点）
- 付费分层决定运营资源投放：鲸鱼做 1v1，海豚做活动，小鱼做首充转化
- 流失预警的业务价值：高价值用户流失前干预的 ROI 远高于拉新，且干预手段按充值历史差异化
- 新手转化漏斗：最陡的一级就是最大流失点（本演示在"完成新手引导→次日回访"），对应排查新手引导第 3 步
- LTV 曲线：D1 ¥2.1 → D30 ¥57.3，付费渗透主要发生在 D3 前 → 广告买量回收周期可按 D7 LTV 估算
